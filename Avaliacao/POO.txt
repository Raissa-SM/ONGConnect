Atividades e requisitos:
- Criar um projeto de WebService REST BackEnd.
- O BackEnd pode ser desenvolvido em Web API ASP.NET com C# como fizemos, ou pode-se utilizar outra linguagem, desde que seguindo metodologia REST e orientado a objetos.
- Integrar o projeto com banco de dados.
- O projeto deve trabalhar com pelo menos 4 entidades.
- Criar rotina de controllers para disponibilizar os serviços e recursos do WebService.
- Criar a rotina de persistência com o banco de dados (CRUD).
- Tema livre.
- Individual ou em dupla.

Os testes com o Webservice será realizado com a ferramenta swagger, Insomnia, postman ou similar.
Será avaliado o BackEnd. Não será avaliado FrontEnd, este será um trabalho futuro.






Projeto FrontEnd

Atividades e requisitos:

- Criar um projeto de Frontend para interagir com o WebService REST Backend desenvolvido anteriormente.
- O Frontend pode ser desenvolvido em React JS como fizemos em sala, ou também pode ser utilizado outra linguagem, desde que, orientada a objetos.
- Integrar o Frontend com o Backend.
- Criar rotinas de acesso aos serviços e recursos do WebService. Deve ser implementado pelo menos quatro serviços, cada serviço com os métodos GET, POST, PUT e DELETE do CRUD.
- Será avaliado o visual do projeto, a implementação das rotinas de consumo dos serviços do WebService, o funcionamento da integração com WebService e a estrutura do código fonte.
- Individual ou em dupla conforme trabalhado no Backend.

DECISÃO DO PROJETO:
A integração Frontend-Backend é feita via Eloquent ORM diretamente nos Web Controllers (app/Http/Controllers/Web/),
sem necessidade de chamadas HTTP para os endpoints /api/... do WebService.
O Blade frontend e a REST API compartilham o mesmo projeto Laravel e a mesma camada de modelo,
o que é equivalente à integração exigida. Os endpoints REST continuam disponíveis e documentados
via Swagger para testes externos (Postman/Insomnia).
